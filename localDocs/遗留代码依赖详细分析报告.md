// BuildingGeneratorFactory.ts
class BuildingGeneratorFactory {
  private generators: Map<ProductionCategory, IBuildingGenerator>

  constructor(config: IBuildingGeneratorConfig) {
    this.generators = new Map([
      [PRODUCTION_CATEGORY.smelter, new SmelterGenerator(config)],
      [PRODUCTION_CATEGORY.assembling, new AssemblingGenerator(config)],

- 易于测试：每个生成器可独立测试

## 十、结论

本次系统性比对分析全面梳理了遗留代码与新架构的差异，识别了以下关键问题：

1. **架构问题**: 全局变量污染、职责混乱、无模块化
2. **性能问题**: 同步阻塞、内存浪费、重复计算
3. **逻辑问题**: 状态残留、时序依赖、数据污染
4. **可维护性问题**: 无类型约束、硬编码配置、无测试覆盖

新架构通过以下改进解决了这些问题：

1. **服务化架构**: RecipeDataService、UpdateAllService、BlueprintService 等服务类
2. **状态管理**: Pinia Store + 类型安全
3. **性能优化**: 异步加载、Worker计算、缓存机制
4. **可维护性**: TypeScript、模块化、测试覆盖

建议继续保持当前架构方向，逐步清理遗留代码依赖，最终实现完全独立的新架构。
