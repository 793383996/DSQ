## 3. 完整初始化流程与上下游调用链（现行）

### 3.1 初始化主流程

1. `index.html` 顺序加载基础脚本：监控、i18n、`dom.legacy`、核心数据与 UI 逻辑。
2. `data.bootstrap.js` 在 `DOMContentLoaded` 后并行触发：
   - `fetch(data.json)` 加载游戏资源并设置 `window.game_data`。
   - 调用 `f_init()` 初始化 Vue 实例、事件绑定、默认设置加载。
3. `index.events.js` 在同一生命周期执行：
   - 加载 `quote/*` 说明区块（locale 优先，失败回退）。
   - 绑定全局点击与选择事件（需求新增、重置、蓝图生成等）。
4. 页面进入可交互状态后，控制区改动统一进入 `scheduleUpdateAll()`，再由 `update_all()` 重算并刷新结果区。

### 3.2 上游输入 -> 下游输出

1. 上游输入源：控制区表单、需求弹层（`UIselector`）、拆分弹层（`Split`）、更多设置（`MoreSetting`）。
2. 中游状态层：`settings/settings_time/settings_pf/xqs` 与配方索引。
3. 下游计算层：配方展开、设备/传送带/增产剂计算、蓝图编码。
4. 下游展示层：Vue 渲染结果表、统计汇总、蓝图复制与提示。

### 3.3 存储与多语言契约

1. 存储契约：`localStorage` 为唯一长期存储；legacy cookie 仅做一次性迁移读取。
2. 多语言契约：`DSQI18n` 负责文案切换，说明区块遵循 locale -> fallback 加载策略。
3. 页面契约：不再暴露/依赖 `window.$` 与 `window.jQuery`。
