# 重构验收矩阵

日期：2026-04-24  
适用阶段：Phase 0 之后的所有重构阶段

## 1. 使用方式

1. 每进入一个新阶段前，先确认本矩阵对应场景仍可验证
2. 每阶段结束后，至少跑完“自动化必跑”项
3. 对尚未自动化覆盖的项，必须补手工记录

## 2. 核心用户流程验收

| 编号 | 场景 | 验收点 | 自动化现状 | 放行要求 |
| ---- | ---- | ---- | ---- | ---- |
| R01 | 首页加载 | 页面正常渲染，无致命脚本错误 | 已有 smoke / integration / e2e | 必跑 |
| R02 | 语言切换 | `zh-CN/en-US` 切换成功，刷新后保留 | 已有 e2e | 必跑 |
| R03 | 添加需求 | 可从选择器添加物品需求 | 已有 e2e | 必跑 |
| R04 | 编辑需求数量 | 需求编辑后结果同步更新 | 部分覆盖 | 必跑 |
| R05 | 删除需求 | 右键删除后结果同步更新 | 部分覆盖 | 必跑 |
| R06 | 配方切换 | 行内配方切换成功，结果正确刷新 | 部分覆盖 | 必跑 |
| R07 | 设备切换 | 行内设备切换成功，结果正确刷新 | 部分覆盖 | 必跑 |
| R08 | 增产剂切换 | 行内增产剂类型/效果切换成功 | 部分覆盖 | 必跑 |
| R09 | 全局设置切换 | 全局设备/增产剂/速度配置生效 | 已有 unit + 部分页面覆盖 | 必跑 |
| R10 | 排除项操作 | 排除单项/重置排除成功 | 部分覆盖 | 必跑 |
| R11 | 保存方案 | 可保存方案，名称校验正确 | 需补强 | 必跑 |
| R12 | 加载方案 | 保存后的方案可重新载入 | 需补强 | 必跑 |
| R13 | 重置方案/需求 | 重置后状态正确清空 | 部分覆盖 | 必跑 |
| R14 | 说明区块加载 | `quote/` 内容加载成功，失败可回退 | 已有 unit | 必跑 |
| R15 | 蓝图生成 | 蓝图可生成，异常会给出提示 | 已有 blueprint / e2e | 必跑 |
| R16 | HTTPS 复制 | HTTPS 下复制成功，HTTP 下受限提示正确 | 已有 e2e | 必跑 |

## 3. SEO 与静态资源验收

| 编号 | 场景 | 验收点 | 自动化现状 | 放行要求 |
| ---- | ---- | ---- | ---- | ---- |
| S01 | canonical | 与语言状态一致 | 已有 e2e / seo-check | 必跑 |
| S02 | hreflang | `zh-CN` / `en-US` / `x-default` 在位 | 已有 integration / seo-check | 必跑 |
| S03 | JSON-LD | `WebApplication` / `BreadcrumbList` / `FAQPage` 在位 | 已有 e2e / seo-check | 必跑 |
| S04 | robots / sitemap | 关键静态文件存在 | 已有 integration / verify-vite-dist | 必跑 |
| S05 | 法律页 | 隐私、条款、Cookie、安全页可访问 | 已有 integration | 必跑 |

## 4. 工程门禁验收

| 编号 | 项目 | 验收点 | 命令 |
| ---- | ---- | ---- | ---- |
| Q01 | 类型检查 | 新 TS/Vue 代码类型通过 | `npm run typecheck` |
| Q02 | Lint | 不引入新的阻塞性 lint 错误 | `npm run lint` |
| Q03 | jQuery 基线 | 一方脚本不回退到 jQuery 依赖 | `npm run jquery:check` |
| Q04 | 单元测试 | 领域逻辑与基础服务回归通过 | `npm run test:unit` |
| Q05 | 构建 | `dist-vite/` 成功产出 | `npm run build` |
| Q06 | 构建校验 | 关键产物完整、哈希资源在位 | `npm run verify:vite-dist` |
| Q07 | 集成测试 | 关键路由、标记、静态资源通过 | `npm run test:integration` |
| Q08 | E2E | 主流程浏览器级回归通过 | `npm run test:e2e` |
| Q09 | a11y | 关键可访问性检查通过 | `npm run test:a11y` |

## 5. 每阶段最低放行组合

### Phase 0

1. 文档已写入
2. `README.md` 不再指向失效文档

### Phase 1

1. `npm run typecheck`
2. `npm run test:unit`
3. `npm run lint`
4. `npm run jquery:check`
5. `npm run build`

### Phase 2

1. `Phase 1` 全部项目
2. 迁移模块新增单元测试

### Phase 3

1. `Phase 2` 全部项目
2. Store 契约测试
3. 手工验证 `R03 ~ R13`

### Phase 4

1. `Phase 3` 全部项目
2. `npm run test:integration`
3. `npm run test:e2e`
4. `npm run test:a11y`

### Phase 5

1. `npm run ci:check`
2. 遗留依赖退场清单复核
3. 发布产物与回滚预案复核

## 7. 结论

后续重构不允许只以“能 build”作为通过标准。任何阶段如果打断：

1. 核心需求链路
2. 语言持久化
3. 蓝图生成
4. SEO 标记
5. 法律页访问

则该阶段视为不合格，必须回退到修复状态后再继续推进。
