Enter the required item output per minute, then click the blue button to choose the item.
Reference throughput: Belt 360/min, Mk.II Belt 720/min, Mk.III Belt 1800/min.
Actions available on the left side of each item:
1. Tag: mark an item (change row color), for example when that line is already built.
2. Multi-recipe: calculate one item with multiple recipes at the same time.
3. Exclude: remove one item from requirement calculation.
Mining machine defaults to 6 veins; Advanced Mining Machine defaults to 20 veins.
Sprayer acceleration follows proliferator behavior, so you can configure it directly with proliferator settings.
Critical Photon, oil rate, Fractionator, Orbital Collector, station stacking, and Advanced Mining Machine are configurable in Settings.
Proliferator currently supports total spray demand only (not exact consumed item counting).
For blueprint generation, configuration items are moved to top settings. Currently supported production facilities: (Plane) Smelter, Assembler, Refinery, Collider, (Quantum) Chemical Plant, and Lab.
