Security Disclosure

Updated on: 2026-03-24

If you discover a security issue in this website, please contact us privately via repository Issue (tagged as security) and avoid public disclosure of sensitive details.

1. Recommended report details

Vulnerability type, impact scope, reproduction steps, risk assessment, and optional mitigation suggestions.

2. Response commitment

We will acknowledge receipt within 72 hours and provide a remediation plan or mitigation strategy after assessment.

3. Detailed process

Please refer to SECURITY.md in the repository root for the full response process.
