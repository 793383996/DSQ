Privacy Policy

Effective date: 2026-03-24

This website is a frontend utility tool. User registration is not required by default. We only process the minimum data needed for stable operation and troubleshooting.

1. Data we may collect

When monitoring is enabled, we may collect anonymous error information, performance metrics (for example blueprint generation duration), route path, version, and related runtime context.

2. Data we do not collect

We do not actively collect sensitive personal information such as ID number, phone number, email address, or bank card number.

3. Data usage

Data is only used for site availability monitoring, issue diagnosis, performance optimization, and security auditing. It is not used for ad targeting.

4. Storage and retention

Required configuration data (for example settings and saved plans) may be stored in your browser. Remote monitoring retention follows operations policy and is cleaned periodically.

5. Your choices

You can remove local data by clearing browser cache or storage. If you have questions about data handling, please use the contact information on the Security page.
