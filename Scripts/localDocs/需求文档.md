# 戴森球计划量产量化计算器 - 需求文档

## 1. 产品概述

### 1.1 产品定位

《戴森球计划》自动化量产计算器，帮助玩家规划工厂生产线，自动计算生产某个产品所需的原材料、设备数量、电力消耗等。

### 1.2 目标用户

| 用户类型 | 描述 | 核心需求 |
|---------|------|---------|
| 新手玩家 | 刚接触游戏，对生产链不熟悉 | 简单易用，快速了解生产需求 |
| 中级玩家 | 已掌握基础，追求效率优化 | 精确计算，蓝图生成 |
| 高级玩家 | 大规模工厂规划，追求极致效率 | 堆叠布局，高级配置，蓝图分享 |

### 1.3 核心价值

- **自动化计算**：输入目标产量，自动递归计算所有原料需求
- **蓝图生成**：一键生成可导入游戏的蓝图字符串
- **灵活配置**：支持设备升级、增产剂、传送带等级等配置

## 6. 约束与假设

### 6.1 技术约束

- 前端框架：Vue 3 + TypeScript
- 状态管理：Pinia
- 构建工具：Vite
- 不依赖后端服务（纯前端应用）

### 6.2 业务约束

- 配方数据基于游戏版本 0.9.26.13026
- 蓝图格式遵循游戏蓝图协议
- 不支持游戏 Mod 配方

### 6.3 假设条件

- 用户已了解《戴森球计划》基本玩法
- 用户浏览器支持现代 Web API
- 用户网络可访问 CDN 资源
