# 堆叠模块重构详细方案

## 1. 堆叠功能概述

建筑堆叠将一条平铺的产线蓝图，垂直复制到多个 z 层（z=0, 10, 20, 30），使相同产能占用更小的地表面积。

```
核心设计思想：
1. init() 缩减 num（除Lab外）
   → 60个设备 → ceil(60/4) = 15个设备/层
   → Lab.num 不缩减，保持完整

2. generateBuildings() 单层布局
   → 15个设备 + 15个分拣器在z=0
   → 完整Lab在z=0布局

3. generateConveyorBelts() rate放大
   → rate × stackLayers（支撑所有层总产能）
   → z=0传送带汇聚所有层产物，按总产能设计

4. cloneToStackLayers() 克隆
   → 15设备 × 3份 → z=10,20,30
   → 15分拣器 × 3份 → z=10,20,30
   → 每层独立地基（z=-10, 0, 10, 20）
   → Lab不克隆

5. 共享传送带网络
   → 所有层的分拣器连接到z=0的传送带
   → z=0传送带支撑所有层总产能
   → 4层并行工作，总产能 = 60min
```

## 3. 核心代码分析

### 3.1 Phase 1: init() num 缩减

```javascript
// blueprint.js L2062-2072
if (this.config.stackLayers > 1) {
  for (let subRecipe of this.recipe.subRecipes) {
    if (subRecipe.building) {
      // 排除 Lab（不缩减num，保持完整产能）
      if (buildingMap[subRecipe.building.name].category !== productionCategory.lab) {
        subRecipe.building.num = Math.ceil(
          subRecipe.building.num / this.config.stackLayers
        );
      }
    }
  }
}
```

**关键点**：
- `Math.ceil` 向上取整保证每层至少 1 个建筑
- Lab 不缩减，保持完整产能
- 缩减在 `calculateBlueprintArea()` 之前执行

### 3.2 Phase 3: generateConveyorBelts() rate 放大

```javascript
// blueprint.js L2378-2412
const stackLayers = this.config.stackLayers || 1;
if (stackLayers > 1) {
  // itemSummary rate 放大
  for (let key in itemSummary) {
    itemSummary[key].rate *= stackLayers;
    if (itemSummary[key].inputRate !== undefined) {
      itemSummary[key].inputRate *= stackLayers;
    }
  }
  // 分拣器 rate 放大
  for (let itemName in this.sorters) {
    if (this.sorters[itemName].output) {
      for (let s of this.sorters[itemName].output) {
        s.rate *= stackLayers;
      }
    }
    if (this.sorters[itemName].input) {
      for (let s of this.sorters[itemName].input) {
        s.rate *= stackLayers;
      }
    }
  }
}

// 分拣器分配策略
const sortersPerNode = stackLayers > 1
  ? Math.max(1, Math.floor(this.config.maxSorterNumOneBelt / stackLayers))
  : this.config.maxSorterNumOneBelt;
```

**关键点**：
- rate 放大支撑所有层总产能
- 分拣器按比例分配，保证克隆后不超限
- z=0 传送带汇聚所有层产物

## 5. Index 重映射机制

```
index 引用重映射规则：

1. outputObjIdx（分拣器输出目标）：
   - 克隆分拣器 → 同层克隆设备（通过 indexMap）
   - 克隆分拣器 → z=0 传送带（保持原值）

2. inputObjIdx（设备输入源）：
   - 克隆设备 → 该层对应的地基
     layer=1 → z=10 设备 → z=0 地基 (foundationStartIndex + 1)
     layer=2 → z=20 设备 → z=10 地基 (foundationStartIndex + 2)
   - 克隆分拣器 → 同层克隆设备（通过 indexMap）

3. 共享传送带网络：
   - 所有层的分拣器 outputObjIdx 指向 z=0 的传送带
   - 这样 4 层都连接到同一套传送带网络
```

## 8. 堆叠服务实现

创建 `src/core/blueprint/services/StackService.ts`：

```typescript
import type { 
  IStackConfig, 
  ICloneFilter, 
  ICloneResult, 
  ISubRecipe,
  IItemSummary,
  ISorterMap,
  IBlueprintBuilding 
} from '../types'
import { buildingMap, productionCategory } from '../constants/buildingMap'

/**
 * 建筑堆叠服务
 * 架构师注：堆叠逻辑必须与原 blueprint.js 完全一致
 */
export class StackService {
  private config: IStackConfig
  private zStep: number = 10

  constructor(config: IStackConfig) {
    this.config = config
  }

  /**
   * Phase 1: 缩减建筑数量
   * 非Lab建筑 num = ceil(num / stackLayers)
   */
  reduceBuildingNum(subRecipes: ISubRecipe[]): void {
    if (this.config.stackLayers <= 1) return

    for (const subRecipe of subRecipes) {
      if (subRecipe.building) {
        const buildingInfo = buildingMap[subRecipe.building.name]
        // Lab 不缩减
        if (buildingInfo.category !== productionCategory.lab) {
          subRecipe.building.num = Math.ceil(
            subRecipe.building.num / this.config.stackLayers
          )
        }
      }
    }
  }

  /**
   * Phase 3: 放大物料速率
   * rate *= stackLayers
   */
  scaleItemSummary(itemSummary: IItemSummary): void {
    if (this.config.stackLayers <= 1) return

    for (const key in itemSummary) {
      itemSummary[key].rate *= this.config.stackLayers
      if (itemSummary[key].inputRate !== undefined) {
        itemSummary[key].inputRate *= this.config.stackLayers
      }
    }
  }

  /**
   * Phase 3: 放大分拣器速率
   */
  scaleSorters(sorters: ISorterMap): void {
    if (this.config.stackLayers <= 1) return

    for (const itemName in sorters) {
      if (sorters[itemName].output) {
        for (const s of sorters[itemName].output!) {
          s.rate *= this.config.stackLayers
        }
      }
      if (sorters[itemName].input) {
        for (const s of sorters[itemName].input!) {
          s.rate *= this.config.stackLayers
        }
      }
    }
  }

  /**
   * 计算每节点分拣器数量
   */
  getSortersPerNode(): number {
    if (this.config.stackLayers <= 1) {
      return this.config.maxSorterNumOneBelt
    }
    return Math.max(1, Math.floor(this.config.maxSorterNumOneBelt / this.config.stackLayers))
  }

  /**
   * Phase 4: 克隆建筑到高层
   */
  cloneToStackLayers(
    baseBuildings: IBlueprintBuilding[],
    buildingIndex: number
  ): ICloneResult {
    if (this.config.stackLayers <= 1) {
      return { buildings: [], foundations: [], indexMap: new Map() }
    }

    const result: ICloneResult = {
      buildings: [],
      foundations: [],
      indexMap: new Map()
    }

    // 1. 生成地基
    const foundationStartIndex = baseBuildings.length + 1
    for (let layer = 0; layer < this.config.stackLayers; layer++) {
      const foundationZ = (layer - 1) * this.zStep
      result.foundations.push(this.createFoundation(foundationZ))
    }

    // 2. 创建过滤规则
    const filter = this.createCloneFilter(baseBuildings)

    // 3. 过滤可克隆建筑
    const cloneableBuildings = baseBuildings.filter(b => this.isCloneable(b, filter))

    // 4. 逐层克隆
    for (let layer = 1; layer < this.config.stackLayers; layer++) {
      const zOffset = layer * this.zStep
      const layerResult = this.cloneLayer(
        cloneableBuildings,
        layer,
        zOffset,
        foundationStartIndex,
        buildingIndex
      )
      result.buildings.push(...layerResult.buildings)
      layerResult.indexMap.forEach((v, k) => result.indexMap.set(k, v))
    }

    return result
  }

  /**
   * 创建克隆过滤规则
   */
  private createCloneFilter(buildings: IBlueprintBuilding[]): ICloneFilter {
    const labItemIds = new Set([
      buildingMap.lab.itemId,
      buildingMap['自演化研究站'].itemId
    ])
    const beltItemIds = new Set([2001, 2002, 2003])

    const labIndices = new Set<number>()
    for (const b of buildings) {
      if (labItemIds.has(b.itemId)) {
        labIndices.add(b.index)
      }
    }

    return {
      labItemIds,
      beltItemIds,
      sprayCoaterItemId: buildingMap.sprayCoater.itemId,
      labIndices
    }
  }

  /**
   * 判断建筑是否可克隆
   */
  private isCloneable(building: IBlueprintBuilding, filter: ICloneFilter): boolean {
    if (filter.labItemIds.has(building.itemId)) return false
    if (filter.labIndices.has(building.inputObjIdx) || filter.labIndices.has(building.outputObjIdx)) {
      return false
    }
    if (filter.beltItemIds.has(building.itemId)) return false
    if (building.itemId === filter.sprayCoaterItemId) return false

    return true
  }

  /**
   * 克隆单层建筑
   */
  private cloneLayer(
    buildings: IBlueprintBuilding[],
    layer: number,
    zOffset: number,
    foundationStartIndex: number,
    startIndex: number
  ): { buildings: IBlueprintBuilding[], indexMap: Map<number, number> } {
    const indexMap = new Map<number, number>()
    const clonedBuildings: IBlueprintBuilding[] = []

    let nextIndex = startIndex + 1
    for (const base of buildings) {
      indexMap.set(base.index, nextIndex)
      nextIndex++
    }

    for (const base of buildings) {
      const clone = this.cloneBuilding(base, layer, zOffset, foundationStartIndex, indexMap)
      clonedBuildings.push(clone)
    }

    return { buildings: clonedBuildings, indexMap }
  }

  /**
   * 克隆单个建筑
   */
  private cloneBuilding(
    base: IBlueprintBuilding,
    layer: number,
    zOffset: number,
    foundationStartIndex: number,
    indexMap: Map<number, number>
  ): IBlueprintBuilding {
    const clone: IBlueprintBuilding = {
      itemId: base.itemId,
      index: indexMap.get(base.index)!,
      localOffset: base.localOffset ? [
        { 
          x: base.localOffset[0].x, 
          y: base.localOffset[0].y, 
          z: base.localOffset[0].z + zOffset 
        },
        { 
          x: base.localOffset[1].x, 
          y: base.localOffset[1].y, 
          z: base.localOffset[1].z + zOffset 
        }
      ] : null,
      yaw: [...base.yaw],
      recipeId: base.recipeId,
      filterId: base.filterId,
      inputObjIdx: this.remapInputIndex(base.inputObjIdx, layer, foundationStartIndex, indexMap),
      outputObjIdx: this.remapOutputIndex(base.outputObjIdx, indexMap),
      parameters: base.parameters ? { ...base.parameters } : null
    }

    return clone
  }

  /**
   * 重映射输入索引
   */
  private remapInputIndex(
    originalIndex: number,
    layer: number,
    foundationStartIndex: number,
    indexMap: Map<number, number>
  ): number {
    if (originalIndex < 0) return -1
    
    if (indexMap.has(originalIndex)) {
      return indexMap.get(originalIndex)!
    }
    
    return foundationStartIndex + layer
  }

  /**
   * 重映射输出索引
   */
  private remapOutputIndex(
    originalIndex: number,
    indexMap: Map<number, number>
  ): number {
    if (originalIndex < 0) return -1
    
    if (indexMap.has(originalIndex)) {
      return indexMap.get(originalIndex)!
    }
    
    return originalIndex
  }

  /**
   * 创建地基建筑
   */
  private createFoundation(z: number): IBlueprintBuilding {
    return {
      itemId: 1101,
      index: 0,
      localOffset: [
        { x: 0, y: 0, z },
        { x: 0, y: 0, z }
      ],
      yaw: [0, 0],
      recipeId: 0,
      filterId: 0,
      inputObjIdx: -1,
      outputObjIdx: -1,
      parameters: null
    }
  }
}
```

## 9. Index 重映射工具

创建 `src/core/blueprint/utils/IndexMapper.ts`：

```typescript
import type { IBlueprintBuilding } from '../types'

/**
 * Index 重映射工具
 * 架构师注：确保克隆后建筑引用正确
 */
export class IndexMapper {
  private mapping: Map<number, number> = new Map()

  /**
   * 添加映射
   */
  addMapping(original: number, cloned: number): void {
    this.mapping.set(original, cloned)
  }

  /**
   * 获取映射
   */
  getMapping(original: number): number | undefined {
    return this.mapping.get(original)
  }

  /**
   * 检查是否存在映射
   */
  hasMapping(original: number): boolean {
    return this.mapping.has(original)
  }

  /**
   * 批量重映射建筑索引
   */
  remapBuildings(buildings: IBlueprintBuilding[]): void {
    for (const building of buildings) {
      if (building.inputObjIdx >= 0 && this.hasMapping(building.inputObjIdx)) {
        building.inputObjIdx = this.getMapping(building.inputObjIdx)!
      }
      if (building.outputObjIdx >= 0 && this.hasMapping(building.outputObjIdx)) {
        building.outputObjIdx = this.getMapping(building.outputObjIdx)!
      }
    }
  }

  /**
   * 获取所有映射
   */
  getAllMappings(): Map<number, number> {
    return new Map(this.mapping)
  }

  /**
   * 清空映射
   */
  clear(): void {
    this.mapping.clear()
  }
}
```

import { StackService } from '../src/core/blueprint/services/StackService'
import type { IStackConfig, ISubRecipe, IItemSummary, IBlueprintBuilding } from '../src/core/blueprint/types'

describe('StackService', () => {
  const defaultConfig: IStackConfig = {
    stackLayers: 4,
    maxLabLayers: 4,
    maxSorterNumOneBelt: 12,
    zStep: 10
  }

  describe('reduceBuildingNum', () => {
    it('should reduce non-Lab building num by stackLayers', () => {
      const service = new StackService(defaultConfig)
      const subRecipes: ISubRecipe[] = [
        { building: { name: 'assemblingMachineMk1', num: 60 } },
        { building: { name: 'lab', num: 4 } }
      ]

      service.reduceBuildingNum(subRecipes)

      expect(subRecipes[0].building!.num).toBe(15)
      expect(subRecipes[1].building!.num).toBe(4)
    })

    it('should not reduce when stackLayers is 1', () => {
      const config = { ...defaultConfig, stackLayers: 1 }
      const service = new StackService(config)
      const subRecipes: ISubRecipe[] = [
        { building: { name: 'assemblingMachineMk1', num: 60 } }
      ]

      service.reduceBuildingNum(subRecipes)

      expect(subRecipes[0].building!.num).toBe(60)
    })

    it('should use ceil for rounding', () => {
      const service = new StackService(defaultConfig)
      const subRecipes: ISubRecipe[] = [
        { building: { name: 'assemblingMachineMk1', num: 61 } }
      ]

      service.reduceBuildingNum(subRecipes)

      expect(subRecipes[0].building!.num).toBe(16)
    })
  })

  describe('scaleItemSummary', () => {
    it('should scale rate by stackLayers', () => {
      const service = new StackService(defaultConfig)
      const itemSummary: IItemSummary = {
        ironOre: { rate: 100, inputRate: 50 }
      }

      service.scaleItemSummary(itemSummary)

      expect(itemSummary.ironOre.rate).toBe(400)
      expect(itemSummary.ironOre.inputRate).toBe(200)
    })

    it('should not scale when stackLayers is 1', () => {
      const config = { ...defaultConfig, stackLayers: 1 }
      const service = new StackService(config)
      const itemSummary: IItemSummary = {
        ironOre: { rate: 100 }
      }

      service.scaleItemSummary(itemSummary)

      expect(itemSummary.ironOre.rate).toBe(100)
    })
  })

  describe('getSortersPerNode', () => {
    it('should return maxSorterNumOneBelt when stackLayers is 1', () => {
      const config = { ...defaultConfig, stackLayers: 1 }
      const service = new StackService(config)

      expect(service.getSortersPerNode()).toBe(12)
    })

    it('should return floor(max/stackLayers) when stackLayers > 1', () => {
      const service = new StackService(defaultConfig)

      expect(service.getSortersPerNode()).toBe(3)
    })

    it('should return at least 1', () => {
      const config = { ...defaultConfig, maxSorterNumOneBelt: 2, stackLayers: 4 }

  })

## 12. 风险预警

### 12.1 堆叠特有风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Index 引用错误 | 分拣器连接错误建筑 | Baseline 测试覆盖所有引用场景 |
| z 坐标偏移错误 | 建筑重叠或悬空 | 验证 zStep 固定为 10 |
| Lab 过滤遗漏 | Lab 被错误克隆 | 明确 Lab itemId 列表 |
| 传送带共享失败 | 各层产物无法汇聚 | 确保 outputObjIdx 保持原值 |

- [ ] Lab 不缩减 num

- [ ] 传送带不被克隆
- [ ] 喷涂机不被克隆
